# Episode detail surface

## Purpose

Help an authenticated care-team member understand the current state of one monitoring episode, who owns the next step, what has been verified, and which action is appropriate for their role.

## Information order

1. Patient display name, prototype reference, due date, status, and care owner.
2. A four-stage progress summary: testing, report receipt, clinician review, and closure. State what is complete and what is waiting in plain language.
3. Role-authorized care-team actions, grouped by purpose and clearly labeled.
4. Episode record, grouped as ordered tests, coordinator follow-through and barriers, contact history, report receipt, clinician review, and activity history.

Use headings, spacing, and a readable column layout to make these groups distinct. On mobile, stack sections and progress stages in workflow order. Avoid dumping every record into one uninterrupted list.

## Content and safeguards

- Show only the minimum patient display information and prototype reference.
- Separate patient-reported completion from staff-verified test completion and report receipt.
- Never display report contents, laboratory values, generated clinical interpretation, or invented records.
- Provide a plain-language empty message for each absent record type.
- Keep clinical interpretation, next-action decisions, and closure authority with clinicians.
- This is a demonstration environment; use fictional records only.
